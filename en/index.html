MCP and HTTP client

SessionDeskMCP ships with the app and registers from Settings. If a repository has an openapi file, its endpoints are listed and can be called in place, with history.

GET /api/sessions · 200 · 41ms
POST /api/tasks · 201 · 88ms

Repositories and skills

Repositories grouped by org, with logo and color. The Skills tab lists .claude/skills, and one click starts a new session with that skill selected.

ship-session · from request to green
release · from changeset to publish

Read-only

Job files written by Claude Code are only read, never modified. Conversation logs stay, so claude --resume still works.

No tokens stored

GitHub auth is left to gh and its keyring. The app stores no credentials and never leaks them into error messages.

Signed and notarized

Signed with an Apple Developer ID and notarized. No need to strip quarantine attributes.

Install

Three steps.

01

Get the dmg

Download the latest SessionDesk_*.dmg from GitHub Releases.

02

Move to Applications

Do not launch from the dmg. Drag the app into Applications first.

03

Open it

It is notarized, so it opens on double-click. Updates are checked from inside the app.

Start by leaving it open for a day.
