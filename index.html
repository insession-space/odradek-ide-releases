It reads. It does not touch.

Odradek sits next to the tools you already trust, and stays out of their way.

Read-only

Job files written by Claude Code are only read, never modified. Conversation logs stay, so claude --resume still works.

No tokens stored

GitHub auth is left to gh and its keyring. The app stores no credentials and never leaks them into error messages.

Signed and notarized

Signed with an Apple Developer ID and notarized. No need to strip quarantine attributes to open it.

Installing takes a minute.

01

Get the dmg

Download the latest Odradek_*.dmg from GitHub Releases.

02

Move it to Applications

Do not launch it from the dmg. Drag the app into Applications first.

03

Open it

It is notarized, so it opens on a double-click. Updates arrive from inside the app.
